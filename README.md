# Projects Circuit

Interactive portfolio projects page. Drive the Crown V8 around a circuit; each building is a solo project. Approach a building to open its detail card and visit the live link.

## Stack

- Vite + React + TypeScript
- Three.js / React Three Fiber / Drei / Rapier
- Zustand

## Assets (CC0)

- Cars: [Kenney Car Kit](https://kenney.nl/assets/car-kit)
- Track: [Kenney Starter Kit Racing](https://github.com/KenneyNL/Starter-Kit-Racing)
- Buildings: [Kenney City Kit Suburban](https://kenney.nl/assets/city-kit-suburban)

## Develop

```bash
npm install
npm run dev
```

## Deploy

```bash
npx vercel deploy --prod
```
