# Apex Garage

Interactive car tuning lab proof of concept. Garage showcase + live test track with tuning that changes handling in real time.

## Stack

- Vite + React + TypeScript
- Three.js / React Three Fiber / Drei
- Zustand

## Assets (CC0)

- Cars: [Kenney Car Kit](https://kenney.nl/assets/car-kit)
- Track: [Kenney Starter Kit Racing](https://github.com/KenneyNL/Starter-Kit-Racing) / Racing Kit

## Develop

```bash
npm install
npm run dev
```

## Deploy

```bash
npx vercel --prod --yes
```
